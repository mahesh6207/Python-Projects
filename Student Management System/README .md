#student management system
A simple Student Management System id built using python
## Features
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Save student data permanently using JSON
- Load student data when the program starts

## Technologies Used

- Python
- JSON
- VS Code

## Student DetailsThe program stores:

- Student ID
- Name
- Age
- Branch

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Go to the Student Management System folder.
4. Run:

```bash
python3 main.py
